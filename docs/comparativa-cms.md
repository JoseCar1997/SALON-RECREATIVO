\# Comparativa de gestores de contenidos



| | Joomla | Drupal |

|---|---|---|

| Tipo de sitio para el que sirve | Portales, comunidades y sitios multilingües | Sitios con contenido complejo y estructurado |

| Licencia | GPL v2 o posterior | GPL v2 o posterior |

| Tiempo hasta ver la portada | 5-10 minutos | 5 minutos |

| Dificultad del instalador (1-5) | 3 | 2 |

| Base de datos que usa | MariaDB | SQLite |

| Imagen de Docker Hub | joomla | drupal |



\## ¿Qué gestor elegirías para cada caso y por qué?



1\. El blog de un club deportivo: elegiría WordPress porque es sencillo y está pensado para blogs y webs generales.



2\. La web de una universidad, con muchos tipos de contenido: elegiría Drupal porque permite organizar contenido complejo y muy estructurado.



3\. Una revista con secciones en varios idiomas: elegiría Joomla porque está orientado a portales y tiene buen soporte para contenido multilingüe.
